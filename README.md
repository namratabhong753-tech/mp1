Implementation of Queue Using Two Stacks

This project focuses on the implementation of a Queue data structure using two Stacks in Python. A Queue follows the FIFO (First In, First Out) principle, which means the element inserted first is removed first. Since a Stack follows the LIFO (Last In, First Out) principle, two stacks are used to achieve queue functionality.

The project performs basic queue operations such as Enqueue (insertion of an element), Dequeue (removal of an element), and Display (showing the elements in the queue). The two stacks work together to maintain the correct order of elements during insertion and deletion operations.

This implementation helps in understanding the concepts of Stacks, Queues, and data structure operations. It also demonstrates how one data structure can be used to implement another. The project is useful for learning fundamental data structure concepts and their practical applications in computer science.
